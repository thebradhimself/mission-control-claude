> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the configuration described in `docs/superpowers/specs/2026-04-28-mission-control-setup-design.md` so the user has a working, personalized Mission Control instance ready for daily use.

**Architecture:** Pure configuration plan — no new code. We install dependencies, edit three JSON data files (`daemon-config.json`, `field-ops/services.json`, `agents.json`), regenerate `ai-context.md`, then run a manual smoke test through the dev server UI.
